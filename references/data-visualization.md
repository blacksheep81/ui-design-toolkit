# 数据可视化

用途：页面包含图表、指标卡或仪表盘时使用。先确定要回答的问题，再选图形；一张图回答一个问题。做 claude.ai 风格内嵌图表时，[Claude 风格扁平设计规范](claude-design-system.md) 中的复杂度上限优先。

## 先问是否需要图表

- 一两个数字：用指标卡（数值 + 单位 + 对比基准），不画图。
- 需要查具体值、逐行比较多个属性：用表格。
- 需要看趋势、分布、占比或关系：才用图表。

## 选图

| 要回答的问题 | 首选 | 注意 |
| --- | --- | --- |
| 随时间怎么变 | 折线图；时间点少时用柱状图 | 时间在横轴，间隔均匀；同一张图的折线不超过约 4–5 条 |
| 各类别谁大谁小 | 柱状图；类别名长或类别多时用横向条形图 | 按数值排序，除非类别本身有顺序 |
| 部分占整体多少 | 堆叠条形图；类别不超过约 5 个时可用饼图或环形图 | 小份额合并为“其他”；要精确比较时改用条形图 |
| 两个变量有没有关系 | 散点图 | 点多时降低不透明度或分箱 |
| 数值怎么分布 | 直方图、箱线图 | 说明分箱方式 |
| 两个维度交叉的强弱 | 热力图 | 使用顺序色阶并提供图例 |
| 实际值离目标多远 | 进度条、子弹图 | 标出目标线 |

避免：3D 图表、双纵轴（改为上下两张共用横轴的图）、仅为装饰的面积渐变、超过 6–8 个系列挤在一张图里。

## 坐标轴与标注

- 柱状图和条形图的数值轴从 0 开始；折线图可以不从 0 开始，但要让刻度清楚可见。
- 网格线用浅色细线并尽量少；去掉图表外框和多余刻度线。
- 标题写结论或问题（“3 月退款率升至 4.2%”），而不是只写“退款率”；单位写在标题或轴标签里。
- 系列不多时直接在线条末端或柱子上标注名称，少用需要来回对照的图例。
- 数字使用等宽数字（`font-variant-numeric: tabular-nums`），统一小数位和千分位；大数用“万”“亿”或 K、M 缩写并保持一致。
- 时间格式按受众地区书写，见 i18n.md。

## 颜色

- **分类色**：区分无顺序的类别。同一张图不超过约 6–8 种；同一类别在全站所有图表中用同一颜色。
- **顺序色**：表示从小到大，用同一色相由浅到深。
- **发散色**：表示相对中点的正负偏离，两端两种色相，中点用中性色。
- 需要强调某一个系列时，其余系列用灰色，只给重点上色。
- 不单靠颜色区分：加直接标注、线型或标记形状。避免只用红/绿对比表达好坏，同时加上箭头、正负号或文字。
- 图形与背景、相邻色块之间的对比度不低于 3:1（WCAG 非文本对比）；图上的文字按正文对比度要求。
- 暗色模式下重新检查色板：降低饱和度、提高亮度，网格线与轴文字改用暗色模式的对应 token，见 dark-mode.md。

## 指标卡

- 结构：指标名 → 数值（最醒目）→ 对比（环比、同比或目标，带方向与正负号）→ 可选的迷你趋势线。
- 一行不超过 4–6 张；每张卡片的时间范围一致，或在卡片上分别写明。
- 涨跌的好坏取决于指标（退款率上升是坏事），颜色按含义而不是按方向选择。

## 交互与状态

- 悬停或点击显示精确数值；触屏上提供点击替代，不依赖 hover。
- 时间范围、筛选条件变化时保持坐标轴与颜色稳定，避免每次重排造成误读。
- 覆盖加载（与最终图形等高的骨架）、无数据（说明原因和下一步）、部分数据（标明缺失区间，不用 0 或连线填补）、加载失败（可重试）。
- 窄屏减少刻度和系列，或改为横向条形图、指标卡加迷你图；不要把桌面图表等比缩小到文字不可读。

## 可访问性

- 为图表提供文字结论或摘要；复杂图表提供数据表作为替代视图。
- 用 SVG 时给图形加 `role="img"` 和 `aria-label`（或关联的标题与描述）；交互点可用键盘聚焦。
- 动画只用于数据变化时的过渡，遵守减少动态效果偏好。

## 检查

1. 不看标题，能否在 5 秒内说出这张图想表达什么？
2. 去色后还能区分各系列吗？
3. 数值轴起点、单位、时间范围是否写清楚？
4. 数据是真实数据，或已明确标注为示例数据？
