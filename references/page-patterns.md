# 按页面模式的结构与检查

用途：第 1 步确定模式后，读对应小节，得到该类页面的常见结构、取舍和容易出错的地方。结构是起点，不是必须齐全的清单；一个页面混合多种模式时，以主任务所属的模式为准。

## Persuade：落地页、定价页、注册页

目标是让访客理解价值并采取一个行动。

- **首屏**：一句说明“是什么、给谁、得到什么”的标题，一个主 CTA，一个能证明产品存在的画面（真实截图、可交互演示或作品）。首屏只保留一个主行动，次要行动用弱样式。
- **内容顺序**：问题或场景 → 产品如何解决（配真实界面）→ 证据（客户、数据、案例）→ 价格或下一步 → 常见疑问 → 重复 CTA。没有真实证据就不放这一节，不编造指标、评价或客户标志。
- **定价页**：方案不超过 3–4 个，标出推荐项；按用户关心的差异排列功能，而不是按内部模块。价格、周期和限制写清楚，年付/月付切换要显示实际金额。
- **表单**：注册只问当下必需的字段；每多一个字段都要有理由。
- **常见问题**：多个同等醒目的 CTA；每节同样的“标题 + 三张卡片”；首屏被大图或动画占满而看不到说明；移动端 CTA 掉到首屏以下。
- 视觉方向见 anti-slop.md；区块参考见 design-resources.md。

## Operate：后台、管理台、仪表盘、工具

目标是让熟练用户快速、准确、重复地完成操作。密度可以高，但规则要一致。

- **页面骨架**：稳定的导航（侧栏或顶栏）+ 页标题与主操作 + 筛选区 + 内容区。同类页面骨架保持一致，用户不必重新学习。
- **表格**：
  - 列按决策重要性排序，首列是用户用来识别这一行的东西（名称、单号）。
  - 文字左对齐，数字右对齐并使用等宽数字；状态用“文字 + 颜色”的标签。
  - 行高服务于扫描：紧凑档约 36–40px，常规档约 44–52px，按数据量和使用设备选择。
  - 行内操作不超过 2–3 个，其余收进“更多”菜单；危险操作不放在最顺手的位置。
  - 表头固定；列多时固定首列并允许横向滚动；支持排序的列有明确指示。
- **筛选与搜索**：最常用的 2–4 个筛选直接露出，其余放进“更多筛选”；已生效的筛选以可移除的标签显示，并提供“清除全部”。筛选结果为空时保留筛选条件和重置入口。
- **批量操作**：勾选后在表格上方或底部出现操作条，显示已选数量；“全选”要说明是本页还是全部结果。
- **表单与编辑**：标签在输入框上方；相关字段分组；必填与选填只标少数的那一种。校验在离开字段时进行，提交失败时定位到第一个错误并保留已输入内容。长表单分步或分节，显示进度。
- **详情页**：最常看的信息在上，操作按钮位置固定；用分节或标签页组织次要信息，不把所有字段堆成一张大表单。
- **仪表盘**：先回答“现在是否正常、哪里要处理”，再给趋势。指标卡不超过 4–6 个，每个带对比基准（环比、目标）；图表规则见 data-visualization.md。
- **反馈**：操作结果就地显示；耗时操作显示进度并允许继续做别的事；破坏性操作优先提供撤销。
- **常见问题**：把后台做成营销页（大留白、大圆角卡片、装饰渐变）；所有按钮同级；空壳筛选器；分页与“加载更多”混用。

## Read：文档、博客、帮助中心、长文

目标是让人读完并找到要找的内容。

- **正文栏**：单栏，行长约 45–75 个拉丁字符或 25–40 个汉字；正文 16–18px，行高按语言调整（中文见 chinese-typography.md）。
- **层级**：标题级别不跳级；H2、H3 与正文的字号差清楚，标题靠近它引出的段落。
- **导航**：长文提供目录并高亮当前位置；文档站提供侧栏、面包屑、上一篇/下一篇与搜索。
- **内容元素**：代码块有语言标注、复制按钮，长行可横滚而不撑破页面；表格窄屏可横滚；图片有说明文字；提示框（注意、警告）种类不超过 3–4 种且用法固定。
- **链接**：正文链接有下划线或其他非颜色线索；已访问状态可选。
- **常见问题**：正文过宽；浅灰正文；装饰动画干扰阅读；目录与正文抢层级。

## Experience：作品集、品牌站、活动页

目标是让作品或品牌本身被记住。表现力可以更强，但内容仍要找得到。

- **作品优先**：界面元素退后，图片和视频用足尺寸与质量；每件作品有标题、角色和一句背景。
- **节奏**：通过尺寸、留白和对齐的变化建立节奏，避免统一网格里塞满同尺寸缩略图。
- **动效**：可以有一处有编排的重点动效，其余保持克制；滚动驱动的效果不能劫持滚动，也不能让内容在动画结束前不可读。
- **基本可用性不让步**：导航随时可达，联系方式容易找到，文字对比度达标，减少动态效果偏好下有静态版本，移动端不降级为不可用。
- **性能**：大图用合适的尺寸与格式并懒加载；首屏不等待全部资源加载完才显示。
- **常见问题**：加载动画过长；自定义光标或滚动影响操作；作品图被压缩或裁掉重点。

## 混合页面

- 后台里的空状态或新手引导可以借用 Persuade 的写法，但范围限于那个区块。
- 营销站里的文档区按 Read 处理，保留品牌的字体和颜色，去掉装饰。
- 拿不准时回到主任务：这个页面上，用户做成哪一件事才算成功？
