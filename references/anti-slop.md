# 反 AI 模板味清单

用途：没有明确视觉方向时，避免把自由度花在“生成式默认值”上。用户或品牌明确要求某种风格时，以需求为准；下列特征本身不违规，问题在于“不论主题都出现”。

## 1. 先锚定主题，再选风格

- 写下一句话：产品是什么、给谁用、页面主要任务是什么。视觉选择从该主题的行业、材料、场景和行话中取，而不是从“现代 SaaS”取。
- 首屏放主题中最有代表性的东西（真实产品截图、可交互演示、关键数据、作品图），而非默认的“大数字 + 小标签 + 渐变强调”。
- 给出 2–3 个差异明显的方向（如：编辑排版 / 工具密度 / 实物摄影），说明各自取舍，再选一个深入。

## 2. 常见模板特征（出现时需给出理由）

| 类别 | 典型表现 | 替代思路 |
| --- | --- | --- |
| 配色 | 紫→蓝渐变、霓虹光晕、暖米色底 + 陶土橙强调、近黑底 + 单一荧光绿 | 从品牌或主题素材取色；一个主色 + 中性色阶，强调色只用于交互 |
| 字体 | 全站 Inter / 系统默认；衬线大标题 + 单词斜体或变色强调 | 刻意选择 1–2 个字体家族；两种字体需对比明显 |
| 卡片 | 内容全切成同尺寸圆角卡片，统一 `rgba(0,0,0,.1)` 阴影，卡片套卡片 | 先用留白、底色差、分隔线分组；圆角与层级对应 |
| 图标 | 每个标题上方一个圆角方块图标、Lucide 图标铺满 | 只在图标能加速识别时使用 |
| 装饰性结构 | 每节都有全大写字距标签（eyebrow）、01/02/03 编号、`A · B · C` 元信息、按钮文字末尾 `→` | 编号只用于真实序列；标签必须承载信息 |
| 动效 | 每节淡入上滑、每张卡片 hover 浮起 | 一次有编排的入场或一个关键揭示；响应操作的动效优先 |
| 文案 | “赋能”“一站式”“释放潜力”、delve 类空话、三连形容词 | 写具体对象、数字和动作；按钮说明结果 |
| 节奏 | 所有区块居中、间距相同、左右交替图文 | 按内容重要性改变密度与对齐，允许不对称 |

## 3. 中文界面的特有信号

- 中文大标题套用英文“衬线 + 斜体强调”风格：宋体特大字号加斜体，在中文社区常被视为 AI 默认风格（见 SOURCES.md 中 @vikingmute 的讨论）。中文没有真正的斜体，强调改用字重、颜色块或排版位置。
- 中文正文使用系统字体栈（PingFang SC、Microsoft YaHei、Noto Sans SC 等）时注意字重层级不超过 3 档；标题与正文字号比不宜照搬英文的大跨度。
- 中英混排：英文与数字可选独立字体，并检查中英文之间的间距、基线与数字等宽需求。

## 4. 自检

完成后用一句话回答：“如果把品牌名换掉，这个页面还能认出是为谁做的吗？”答案为否时，回到第 1 步换掉至少一个默认值（字体、主色或首屏形式）。
