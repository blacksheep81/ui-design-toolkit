# 暗色模式

用途：项目需要亮、暗两套主题时，在“定设计系统”阶段使用。暗色模式是一套重新映射的 token，不是把亮色反相。项目只有一种主题时不必为了完整性添加另一种。

## 用语义 token，不用字面颜色

组件只引用按用途命名的 token，两套主题各给一个值：

| token | 用途 | 亮色示例 | 暗色示例 |
| --- | --- | --- | --- |
| `bg` | 页面底色 | `#FFFFFF` | `#14161A` |
| `surface` | 卡片、面板 | `#F5F6F8` | `#1C1F24` |
| `surface-raised` | 弹层、菜单 | `#FFFFFF` | `#24282E` |
| `text` | 正文 | `#1A1D21` | `#E6E8EB` |
| `text-muted` | 辅助文字 | `#5A6270` | `#A0A7B3` |
| `border` | 分隔与边框 | `#D5D9DF` | `#2E333A` |
| `primary` | 主操作底色 | `#0F5FD7` | `#7FB0FF` |
| `primary-contrast` | 主操作上的文字 | `#FFFFFF` | `#0B1220` |

示例值的文字对比度已计算：亮色 `text` 16.9:1、`text-muted` 6.2:1（在 `bg` 上）；暗色 `text` 14.8:1、`text-muted` 7.5:1（在 `bg` 上）、6.8:1（在 `surface` 上）；主按钮文字亮色 5.8:1、暗色 8.5:1。换成自己的颜色后需重新测量。

组件代码里不出现 `#fff`、`black` 或 `dark:` 前缀堆叠的字面颜色；需要新颜色时先加 token。

## 暗色下的调整

- **底色**：用深灰而不是纯黑（`#000`），纯黑上的亮色文字容易产生拖影感，也没有余地表达层级。OLED 省电等明确需求除外。
- **文字**：正文用略低于纯白的浅灰；辅助文字不低于 4.5:1。
- **层级用亮度表达**：阴影在深色背景上几乎看不见。越“高”的表面越亮（`bg` → `surface` → `surface-raised`），必要时加一条细边框。
- **强调色**：亮色主题里的深色品牌色放到暗底上对比不足，需要换成更亮、饱和度更低的一档；按钮上的文字颜色也可能要从白色换成深色。
- **语义色**：成功、警告、错误的浅底深字标签在暗色下改为“深色半透明底 + 亮色文字”，重新测对比度。
- **边框与分隔线**：比亮色主题更依赖边框来区分表面，颜色取比表面略亮的灰。
- **图片与插图**：白底图片在暗色界面里很刺眼，可加圆角与细边框、略降亮度，或提供暗色版本。透明背景的标志和图标检查在两种底色上是否都可见。
- **图表**：色板单独调一版，见 data-visualization.md。
- **焦点环**：在两种主题下都要与相邻颜色保持 3:1 以上。

## 实现

```css
:root {
  color-scheme: light dark;
  --bg: #FFFFFF;
  --text: #1A1D21;
}
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --bg: #14161A; --text: #E6E8EB; }
}
:root[data-theme="dark"] { --bg: #14161A; --text: #E6E8EB; }
```

- 默认跟随系统（`prefers-color-scheme`）；提供手动切换时用 `data-theme` 覆盖并记住用户选择，选项为“跟随系统 / 浅色 / 深色”。
- 声明 `color-scheme`，让滚动条、表单控件等浏览器原生界面跟着切换。
- 服务端渲染或静态页面在首次绘制前设置主题属性，避免先闪一下亮色。
- Tailwind v4 与 shadcn/ui：在 `@theme` 或主题变量中定义同名 token，暗色只覆盖变量值，组件类名不变；见 design-md-template.md。
- 主题切换本身不需要过渡动画；若添加，时长要短并遵守减少动态效果偏好。

## 检查

1. 两种主题下分别实测正文、辅助文字、按钮文字、占位符、禁用态和焦点环的对比度。
2. 逐个检查 hover、选中、禁用状态，暗色下这些状态最容易彼此分不清。
3. 检查弹层、下拉菜单、提示条是否能从背景中分辨出来。
4. 检查图片、标志、图表、代码高亮和第三方嵌入内容。
5. 截图时两种主题各截一份，报告实际检查过的主题。

来源：WCAG 2.2 对比度要求、MDN `prefers-color-scheme` 与 `color-scheme` 文档、Material Design 以亮度表达层级的做法的归纳；见 SOURCES.md。
