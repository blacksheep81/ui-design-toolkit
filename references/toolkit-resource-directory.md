# 按问题选择资源

从 [resources.csv](../resources.csv) 的名称、类别和描述中检索，按任务选一到三个参考。

| 问题 | CSV 的 category |
| --- | --- |
| 首屏、导航、后台和产品流程 | 页面与产品参考 |
| 按钮、卡片、表单或现成组件 | 组件与设计系统 |
| 网页动效、微交互、滚动与着色器 | 动效与 3D |
| 图标、字体、配色或背景素材 | 视觉素材 |
| DESIGN.md、设计规范与助手流程 | 设计规范与 Skill |
| 找提示词、风格词与视觉方向 | 提示词与风格 |
| 用 AI 生成页面或原型 | AI 设计与生成 |
| 接入 MCP、写代码、截图或浏览器验证 | 开发与验证工具 |
| 找教程、模板或综合资源目录 | 教程、模板、资源导航 |

保留参考链接与具体采用的设计决定。CSV 的核实日期表示查看过公开来源。空白字段表示尚无核实记录。采用前查看当前功能、框架兼容性、价格和素材许可。
