# 按问题选择资源

从 [resources.csv](../resources.csv) 的名称、类别和描述中检索，按任务选一到三个参考。

| 问题 | 搜索词 |
| --- | --- |
| 首屏、导航、页脚、定价页怎么组织 | 落地页、Hero、导航、页脚、定价 |
| 产品流程或组件怎么做 | 真实 App、组件、设计系统 |
| 想找动效或视觉素材 | 微交互、滚动、3D、玻璃、图标、字体 |
| 想复用品牌设计规范 | DESIGN.md、token、品牌 |
| 需要实现或验证页面 | MCP、浏览器、截图、组件库 |

保留参考链接与具体采用的设计决定。CSV 的核实日期表示查看过公开来源。空白字段表示尚无核实记录。采用前查看当前功能、框架兼容性、价格和素材许可。
